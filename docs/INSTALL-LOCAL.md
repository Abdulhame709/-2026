## خطوات التثبيت (PowerShell)

### 1) تنزيل الكود
```powershell
git clone -b arena/01a0735f-2026 https://github.com/Abdulhame709/-2026.git
cd -2026
```
> بعد دمج الفرع في `main` سيكفي: `git clone https://github.com/Abdulhame709/-2026.git`

### 2) إنشاء قاعدة البيانات
افتح **pgAdmin** (يأتي مع مثبّت PostgreSQL) أو psql ونفّذ:
```sql
CREATE DATABASE reconciliation;
```

### 3) تجهيز الخادم (backend)
```powershell
cd backend
npm install
# كلمة مرور القاعدة التي اخترتها أثناء تثبيت PostgreSQL:
$env:PGPASSWORD = "كلمة_المرور_هنا"
npm run db:migrate   # إنشاء الجداول (5 ملفات هجرة)
npm run db:seed      # بذور البداية: مستخدمون + موردون تجريبيون
```

### 4) تشغيل الخادم
```powershell
npm run dev
# ✓ الخادم يعمل على http://localhost:3000
```

### 5) تشغيل الواجهة (نافذة PowerShell ثانية)
```powershell
cd frontend
npm install
npm run dev
```
ثم افتح المتصفح: **http://localhost:5173**

### 6) أول دخول
| المستخدم | كلمة المرور | الدور |
|---|---|---|
| `admin` | `Admin@2026` | مدير |
| `sami` | `Sami@2026` | مطابِق |
| `viewer` | `Viewer@2026` | مُشاهد |

> غيّر كلمات المرور من شاشة المستخدمين بعد أول دخول.

## ملاحظات مهمة

1. **لا تحتاج سكربت `db:bootstrap` على ويندوز** — هو مخصص لبيئة التطوير (لينكس) التي تنزّل PostgreSQL مضمّناً. على جهازك، PostgreSQL المثبت هو القاعدة.
2. **إعدادات الاتصال** قابلة للضبط بمتغيرات البيئة إن خالفت الافتراضيات:
   `PGHOST` (الافتراضي 127.0.0.1) · `PGPORT` (5432) · `PGUSER` (postgres) · `PGDATABASE` (reconciliation) · `PGPASSWORD` (من البيئة).
3. **النسخ الاحتياطي** من داخل النظام (الإعدادات ← النسخ الاحتياطي) يعمل في كل البيئات — استخدمه دورياً؛ ملفه أحادي يُستعاد بمعاملة واحدة.
4. **الترقية لاحقاً**: `git pull` ثم أعد `npm install` في المجلدين إن تغيّرت التبعيات، ثم `npm run db:migrate` إن وصلت هجرات جديدة.
5. للتشغيل كإنتاج محلي (اختياري): `npm run build` في المجلدين ثم `npm start` في الخادم — لكن `npm run dev` كافٍ للاستخدام اليومي على شبكة داخلية.
