# API — الوحدة 6: التقارير والإعدادات والنسخ الاحتياطي

> قاعدة المسار `/api/v1` · الشركة/النسخ كتابة أدمن، الأسباب إدارة أدمن والقراءة للجميع.

## بيانات الشركة (ترويسة التقارير)

| المسار | الوصف |
|---|---|
| `GET /settings/company` | الإعدادات أو الافتراضي (فراغ + ترتيب العملات YER/USD/SAR) |
| `PUT /settings/company` | `{nameAr إلزامي, nameEn, address, phone, email, reportHeaderNote, logoFileName, currencyOrder}` — تُخزن JSONB في `settings` (`key='company'`) — تدقيق `COMPANY_SETTINGS_UPDATE` |

## أسباب الفروق (إدارة كاملة)

| المسار | الوصف |
|---|---|
| `GET /reason-codes` | القائمة الكاملة `{id, code, nameAr, nameEn, isActive, sortOrder}` مرتبة |
| `POST /reason-codes` | `{nameAr, nameEn}` — الرمز يُشتق آلياً من الاسم الإنجليزي (UPPER_SNAKE + لاحقة تعارض) |
| `PATCH /reason-codes/{id}` | `{isActive?, nameAr?, nameEn?}` |
| `POST /reason-codes/reorder` | `{ids:[...]}` — الترتيب بترتيب المصفوفة |

## النسخ الاحتياطي — محلي 100% (Q16)، أدمن فقط

| المسار | الوصف |
|---|---|
| `POST /backups` | نسخة = ملف JSON واحد في `backend/storage/backups/` بكل جداول الأعمال (18 جدولاً — تشمل المستخدمين بكلماتهم المشفرة: **الملف سري**) + manifest `{version, createdAt, createdBy, counts}` — تدقيق `BACKUP_CREATE` |
| `GET /backups` | القائمة من القرص (الاسم/التاريخ/الحجم/المنشئ/ملخص العدادات) |
| `GET /backups/{name}/download` | تنزيل لحفظ خارجي (R6) — أسماء مُدقَّقة ب_regex (لا اجتياز مسارات) |
| `POST /backups/{name}/restore` | **أخطر عملية**: معاملة واحدة — TRUNCATE CASCADE + إعادة إدراج (OVERRIDING SYSTEM VALUE) + ضبط عدّادات الهوية للجداول الرقمية فقط؛ مصفوفات jsonb تُرمَّز صراحة (مكتشف من الاختبار)؛ `auth_sessions` مستثناة عمداً (الجميع يعيد الدخول)؛ فشل = rollback كامل والقاعدة كما كانت — تدقيق `BACKUP_RESTORE` |
| `DELETE /backups/{name}` | حذف ملف نسخة — تدقيق `BACKUP_DELETE` |

مصيد مُختبَرة أثناء البناء: استرجاع أصلح ثلاثة أخطاء تسلسلياً — مصفوفات JS في أعمدة jsonb (رمز 22P02)، جداول بلا عمود id (settings)، MAX على UUID (source_files).

## الواجهة — كل الشاشات صارت حقيقية

- **التقارير**: تقرير جلسة من الخادم (أرصدة من البنود، نسبة المطابقة المؤكدة، الفروق بأسبابها)
  بترويسة الشركة من الإعدادات + **تفقيط عربي** للمبلغ في خطاب اعتماد الرصيد + علامة مائية
  «مسودة» للجلسات غير المغلقة + أرشيف شجري حقيقي (طرف←عملة←سنة).
- **لوحة المؤشرات**: 4 مؤشرات محسوبة (جلسات مفتوحة، فروق مفتوحة وقيمتها، نسبة أحدث جلسة،
  متأخرة 30 يوماً) + جلسات تحتاج انتباهاً + ترند من الجلسات المغلقة + فروق متأخرة.
- **الإعدادات**: الأسباب (إضافة/تعطيل/ترتيب) · بيانات الشركة · النسخ الاحتياطي
  (إنشاء/تنزيل/حذف/استرجاع بحافز «اكتب استرجاع») — والمستخدمون وسجل التدقيق حقيقيان من Module 1.
- حُذفت آخر الوحدات الوهمية: settingsMock, reportsMock, dashboardMock.
