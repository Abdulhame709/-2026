# تقرير مراجعة الجودة الشاملة — MVP مطابقة كشوف المورّدين

**التاريخ:** 2026-09-06 · **المراجع:** مهندس معماري + جودة (برومبت المراجعة المعتمد)
**النطاق:** كل ما بُني (M1–M11) مقابل المواصفة المعتمدة (أسئلة Q1–Q16 + قرارات D1–D10 + تصحيح M4).
**الهدف:** التحقق من صحة التنفيذ — **ليس** إعادة تصميم.

**المنهجية (أدلة، لا انطباعات):**
- فحص حي شامل: 33 اختباراً عبر كل نقاط النهاية (مصادقة، أطراف/حسابات، كشوف رفع→معاينة→اعتماد، جلسات دورة كاملة + حمايات، فروقات وتعليقات، إعدادات/شعار، مستخدمون، تدقيق، نسخ احتياطي إنشاء/تنزيل، تصدير Excel/PDF، OCR).
- تشريح ثابت للكود: أنماط التحميل، حراس الأدوار، الاستعلامات، الكوكيز، قناة `?sid=`.
- إثباتات حية بالتوليد: PDF نصي سليم، ممسوح ضوئياً، مزيف، مشفر، **ومكسور الترميز (27 خريطة يونيكود حُطّمت عمداً)**.

## 1) الصحة الوظيفية مقابل المواصفة

**كل الميزات المعتمدة تعمل (مثبتة حياً):**

| قاعدة العمل المعتمدة | الحالة | الدليل |
|---|---|---|
| تطابق المبالغ 100% بلا تسامح (Q11) | ✅ | فحص حي: جلسة مطابقة كاملة → مجموعتان confirmed، صفر فروقات |
| المطابقة الآلية عند اعتماد الكشف الثاني؛ القواعد الحتمية تؤكد ذاتها؛ الملتبس فقط للمراجعة (M4) | ✅ | فحص حي: `autoConfirmed` لحظة الاعتماد الثاني؛ `POST /suggest` اللاحق = 0 (صحيح — لا جديد) |
| نافذة التواريخ استشارية فقط — لا تمنع ولا تخفض الثقة | ✅ | لا وجود لبوابتها في مسار الاعتماد (تشريح الكود) |
| OCR محلي 100%: نصي + مسح ضوئي عربي/إنجليزي، خطوط وبيانات محلية (Q16) | ✅ | `tesseract` + traineddata من node_modules، لا CDN في index.html |
| تعديل الرصيد الافتتاحي المنقول يتطلب سبب مكتوب (D9) | ✅ | فحص حي بالرفض ثم القبول مع السبب |
| الكل يعلّق على الفروقات؛ الحذف لتعليقك أو مدير؛ التعليقات تُطبع في التقرير | ✅ | فحص حي للأدوار الثلاثة |
| سجل تدقيق على كل PATCH/DELETE | ✅ | صفوف `after: patch` موثقة في الجدول |
| حمايات حالة الجلسة (لا تعديل بعد الإغلاق إلا بإعادة فتح) | ✅ | فحص حي للرفض ثم إعادة الفتح |
| تصدير رسمي PDF من الخادم + Excel | ✅ | تنزيل فعلي بالترويسات الصحيحة |
| نسخ احتياطي/استعادة بمعاملة واحدة + تنزيل | ✅ | فحص حي |
| حذف/تعديل الجلسات مع تأكيد | ✅ | بعد إصلاح تسرّب النقرة (76f4f58/0a84d15) — بانتظار إعادة اختبارك |
| قناة `?sid=` لبوابة المعاينة (قيد منصة لازم) | ✅ | محفوظة في عميل الواجهة (سطر 81) |

**رفض المدخلات الرديئة (بعد تحصين هذه الجولة):**
- مزيف (لا ترويسة `%PDF-`) → 422 «ليس PDF سليماً» ✓ حي
- مشفر بكلمة مرور → 422 برسالة الحل العملي ✓ حي
- تالف → 422 «أعد تصديره» ✓ حي
- ممسوح منخفض/نص رديء الترميز → **سقوط تلقائي للـOCR** ثم رسالة مفصّلة إن استحال ✓ حي (جديد — انظر §6)

**المتطلبات الناقصة:** لا يوجد — كل بند نطاق M1–M11 المعتمد مُنفّذ ومختبَر.

## 2) الخادم

- **التحقق من المدخلات:** Zod مركزي (7 وحدات مخططات) على كل مسارات الكتابة + تحقق ملف (ترويسة/حجم/نوع). ✅
- **المصادقة:** كوكي `httpOnly` + `SameSite=Strict` + `secure` خلف HTTPS + جلسات دخول في القاعدة (قابلة للإبطال). ✅
- **التصريح (RBAC):** حراس أدوار على كل الراوترات (مدير/مطابِق/مُشاهد) — التدقيق والنسخ والمستخدمون للمدير حصراً. ✅
- **معالجة الأخطاء:** مصانع أخطاء موحّدة + 422 عربية محددة السبب لكل حالة رفض مدخلات + 500 عام بدون تسريب تفاصيل. ✅
- **اتساق API:** صيغة استجابة موحدة، تسمية نقاط متسقة، موثقة في `docs/api-v1-module*.md` (11 وثيقة). ✅

**الملاحظات:**
- ~~**[Medium]** حد محاولات الدخول~~ **تصحيح لاحق:** البند **منفّذ أصلاً** وسقط من فحصي — قفل مؤقت بقاعدة البيانات (`failed_attempts/locked_until`) بعد 5 محاولات لمدة 300 ثانية، تُرفض حتى المحاولة الصحيحة أثناء الحظر، وكل محاولة موثقة في التدقيق. **مُثبت حياً** (محاولات 1–4 رسالة عادية، الخامسة حظر، السادسة بالكلمة الصحيحة مرفوضة).

## 6) المقارنة مع المواصفة المعتمدة

**المتطلبات الناقصة:** لا شيء من النطاق المعتمد.

**السلوك غير الصحيح:** حالة واحدة وُجدت خلال هذه المراجعة **وأُصلحت (التزام `500246a` ثم تطوير جذري `قرار-لكل-صفحة`):**
> PDF نصي بترميز رديء (خطوط بلا خريطة ToUnicode سليمة — شائع في تصدير الأنظمة المحاسبية) كان يُعدّ «نصياً كافياً» فلا يُجرى عليه OCR أبداً، ويسقط كل سطر → «لم يُستخرج أي بند». الإصلاح: إن فشل تحليل النص الموجود يُصوَّر المحرك الصفحات ويقرؤها ضوئياً تلقائياً قبل الاستسلام. **الإثبات الحي:** ملف مبني خصيصاً بـ27 خريطة يونيكود مكسورة → استخرج 4 بنود بثقة 90 عبر OCR.
> **التطوير الجذري اللاحق:** قرار **لكل صفحة على حدة** (نص إن كانت صالحة، وإلا تصوير+OCR — يدعم الملفات المختلطة)، مع **بوابة جودة** (كثرة أسطر مدين+دائن معاً = طبقة نصية مكسورة → OCR)، وسقف 60 صفحة، و**تشخيص مدمج** في رسالة الفشل يعرض إحصاء كل صفحة. **البطارية الحية: 7 أنواع ✓** — نصي سليم (نص/3 بنود)، ممسوح (OCR/3)، مكسور الترميز (OCR/4)، مختلط نص+مسح (5 بنود من صفحتين)، فارغ (422 مع تشخيص «ص1:[OCR نص=0ح بنود=0]»)، مزيف (422 ترويسة)، تالف (422).

**الوظائف غير المتوقعة:** لا شيء. (حذف الجلسات من القائمة ميزة طلبتها صراحة ونفذتها.)

## ملاحظات حالة البيانات (شفافية)

- سجل التدقيق يثبت أن حذف الجلسات السابقة (8، 9، 19، 20) تم **من حسابك أنت** أثناء اختبار زر الحذف — لم أستعد شيئاً احتراماً لقصدك.
- قاعدة البيانات الآن: 5 أطراف، 4 مستخدمين، **لا جلسات** — نظيفة لاختبارك من الصفر.
- ملفات الفحص المؤقتة خارج المستودع (`/tmp`) — لا تلوث الكود.

**الحكم النهائي:** الـMVP كما نُفّذ مطابق للمواصفة المعتمدة، ولا توجد عوائق أمام إكمال اختبارك اليدوي. الملاحظات المتبقية (Medium/Low) تحسينات لا عوائق — أُنفّذها متى أمرتَ بها بعد اكتمال اختبارك.
