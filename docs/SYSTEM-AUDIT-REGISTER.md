# سجل الفحص الشامل — صفحة صفحة وتبويب تبويب

> بدأ 2026-11-28 بطلب المالك: فحص كل أكواد النظام لاستكشاف أخطاء قراءة الملفات
> وتصحيحها وإضافة الميزات الاحترافية. هذا السجل هو الخريطة الحيّة: ما فُحص، وما
> أُصلح، وما بقي، حتى لا يُدّعى فحص لم يحدث.

## طريقة العمل

1. كل وحدة تُفحص في فرع مستقل، مع اختبارات آلية قبل طلب الدمج.
2. «فُحص» تعني: قراءة الشيفرة + تشغيل مسارها الفعلي أو اختبارها آلياً + إصلاح
   ما ظهر. لا تعني «يعمل عند المالك على بياناته».
3. لا تُمس قاعدة بيانات العمل أثناء الفحص؛ اختبارات التكامل تنشئ قواعد مؤقتة.
4. كل بند «متبقٍ» يحتاج عينة حقيقية منزوعة الحساسية أو قرار مالك (نشر، بيانات).

## الوحدة 1 — قراءة ملفات الكشوفات (2026-11-28) ✅

### ما كان يفسد القراءة فعلياً

| العطل | الأثر على المستخدم | الإصلاح |
|---|---|---|
| مبالغ سالبة بصيغة `(1,234.50)` أو `1,234.50-` أو `−` | تُرفض كغير رقمية أو تُقرأ موجبة | `parseAmount` يفهم أقواس المحاسبة والسالب اللاحق وكل إشارات النص |
| عملات موسّعة (SAR/AED/OMR/KWD/درهم/دينار) | تبقى حروفاً فتفشل الخلية | تنظيف عملات أوسع قبل التحليل |
| CSV بترميز Windows-1256 (تصدير Excel العربي) | رفض الملف أو عربية مشوهة | محاولة UTF-8 ثم UTF-16 ثم Windows-1256 |
| CSV بفاصل `;` أو Tab أو سطر `sep=;` | أعمدة ملتصقة/إزاحة كاملة | كشف الفاصل من أول خمسة أسطر ودعم `sep=` |
| تاريخ مع وقت `2026-01-31 10:20` أو `T10:20:00Z` | تاريخ غير صالح → اعتماد ممنوع | نزع الوقت واسم اليوم قبل التحليل |
| تاريخ Excel التسلسلي و`YYYYMMDD` | خلايا فارغة/تواريخ 1970 | دعم التسلسلي (UTC) والرقم المضغوط |
| أسماء الشهور: `31 يناير 2026` / `Jan 31, 2026` | تاريخ غير مفهوم | تحليل أسماء الشهور العربية والإنجليزية |
| غموض `04/05/2026` (يوم/شهر أم شهر/يوم) | تواريخ معكوسة بصمت | كشف الترتيب من القيم + اختيار صيغة التاريخ في الواجهة |
| ترويسة على صفين/خلايا مدمجة | صف الترويسة الفرعي يصبح بنداً | امتداد الترويسة تلقائياً وأخذ أدق اسم عمود |
| صفوف الترويسة المكررة داخل الجدول | بنود وهمية بمبالغ غير رقمية | كشفها بكلمات الأعمدة وتخطّيها مع عدّها |
| صفوف «الإجمالي/المجموع/رصيد افتتاحي/ختامي» | تُحسب كحركات فتفسد المطابقة | فصلها: الافتتاحي/الختامي يُقترحان، والباقي يُتخطّى |
| عمود «الرصيد» فقط | يُعامل كحركة بلا تنبيه كافٍ | يبقى سلوكاً معتمداً مع تحذير صريح في لوحة التعيين |
| «رقم/له/عليه/مدين-دائن» في الترويسات | أعمدة غير معروفة | مرادفات أوسع، و`مدين/دائن` المجمّع → مبلغ |
| ورقة خاطئة في مصنف متعدد الأوراق | رفض أو قراءة ورقة الغلاف | اختيار الورقة من الواجهة وتمريرها للفحص والتحليل |

### ما أُضيف احترافياً

- **اختيار صيغة التاريخ** من لوحة التعيين (ست صيغ) مع اكتشاف تلقائي للترتيب،
  وتُحفظ مع القالب وتُستخدم عند الاعتماد.
- **اختيار ورقة الملف** من نفس اللوحة عند وجود أكثر من ورقة، دون إعادة رفع.
- **عدّاد الصفوف المتخطّاة** يظهر بعد التحليل: «تُخطّي N صف ترويسة/رصيد/إجمالي»
  حتى لا يظن المستخدم أن بنوداً ضاعت.
- **الافتتاحي والختامي المقترحان** من صفوف الكشف نفسها، مع عدم خلط «الإجمالي»
  بالرصيد الختامي الصريح.
- **توحيد محقق الواجهة مع الخادم**: نفس قواعد التاريخ والمبلغ والسالب، فلا يمر
  بند في الواجهة ويفشل عند الاعتماد (أو العكس).
- **قراءة الصيغ الغريبة بأمان**: فاصل عشري معكوس يُستنتج عند فشل إعدادات القالب،
  بدل رفض المبلغ.

### حدود هذه الوحدة

- عينات العمل الحقيقية (ملفات الموردين الفعلية) لم تُرفع للمستودع، والاختبارات

## الوحدات التالية المقترحة

1. **المطابقة**: مراجعة محرك الاقتراحات، حد التسامح، إعادة الفتح، والاعتماد الثنائي.
2. **الجلسات والفروقات**: الحالات، الفلاتر، الإسناد، ومنع الانتقالات غير الصحيحة.
3. **الموردون وتفاصيلهم**: التعديل، الأرصدة الافتتاحية، خريطة المراجع، والسجل.
4. **التقارير والأرشيف**: صحة المجاميع، PDF/Excel، والتصدير الكبير.
5. **الإعدادات والمستخدمون**: الصلاحيات، القوالب، النسخ الاحتياطي، وسجل التدقيق.
6. **المصادقة والجلسات**: انتهاء الصلاحية، تغيير الكلمة، والقناة البديلة داخل الإطار.
