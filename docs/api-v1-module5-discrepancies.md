# API — الوحدة 5: الفروق

> قاعدة المسار `/api/v1` · الكتابة أدمن/مُطابِق، القراءة للجميع · مغلف الخطأ الموحد.

## التوليد الآلي (مدمج بالإغلاق — Module 4)

عند `POST /sessions/{id}/close`: كل بند متبقٍ (>0.005) يصبح **صف فرق حقيقي**:
`ours_only` (بندنا بلا مقابل) / `theirs_only` (بندهم بلا مقابل) — المبلغ المتبقي هو `diff_amount`.
- إغلاق متكرر (بعد إعادة فتح): يُحذف ما وُلِّد سابقاً **ولم يلمسه أحد** (جديد بلا مسؤول/سبب/ملاحظة/ترحيل) — عمل الفريق المحفوظ لا يُمس.
- أنواع amount_diff/date_diff/ref_diff محفوظة بالمخطط لقضايا مقارنة يدوية لاحقة.

## المسارات

| المسار | الوصف |
|---|---|
| `GET /discrepancies?sessionId=&status=&accountId=` | القائمة منضمة ببيانات الجلسة/المورد/البند + اسم السبب والمسؤول |
| `PATCH /discrepancies/{id}` | `{status?, assigneeId?, reasonCodeId?, resolutionNote?}` — أي مزيج؛ resolved/accepted يضبط `resolved_at` |
| `POST /discrepancies/{id}/carry` | `{targetSessionId}` — ترحيل لجلسة **مفتوحة بنفس الحساب فقط**؛ يظهر فيها كمتبقٍ معروف |
| `GET /reason-codes` | الأسباب الثمانية الجاهزة (خصم مبلَّغ، مرتجع غير مقيَّد، دفعة غير موجودة عنده/عندنا، فاتورة غير مقيَّدة، خطأ إدخال، فرق إقفال، أخرى) |

## قواعد العمل

- **الحل/القبول يفرض ملاحظة** (تحقق الواجهة ≥5 أحرف — الخادم يقبل الحقل بحد 500).
- مسؤول/سبب غير موجود = `VALIDATION_FAILED` رسالة واضحة (ترجمة FK، لا 500).
- الترحيل لا ينسخ بل **يشير** (`carried_to_session_id`) — أصل الفرق وتاريخه محفوظان.
- التدقيق: `DISCREPANCY_UPDATE`, `DISCREPANCY_CARRY` (+ `SESSION_CLOSE` يحمل عدد الفروق).

## الواجهة

- **صفحة الفروق**: حقيقية بفلاتر (طرف/عملة/نوع/حالة/مسؤول/متأخرة 30 يوماً + بحث) وأعمار ملونة
  وعدادات مفتوحة/متأخرة؛ تدعم `?session=N` (روابط شاشة العمل بعد الإغلاق).
- **الدرج المنزلق**: القيم المقارنة + السبب + المسؤول + بدء متابعة + حل/قبول بملاحظة + الترحيل
  (قائمة الجلسات المفتوحة لنفس الحساب). صلاحية الكتابة أدمن/مُطابِق — والمطالعة للجميع.
- تسمية نافذة التاريخ في إعدادات الحساب أصبحت «تقارب التاريخ الإرشادي» — **ليست شرطاً**
  (ملاحظة المالك: القيد المتأخر أسبوعين+ شائع؛ التقارب للترتيب فقط ولا يخفض الثقة).

## مؤجل معلوم

تعليقات الفروق (جدول discrepancy_comments) — بلا مسارات بعد؛ سجل التدقيق يغطي التتبع حتى الوحدة 6.
