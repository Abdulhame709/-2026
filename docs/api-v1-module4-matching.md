# API — الوحدة 4: جلسات المطابقة والمحرّك

> قاعدة المسار: `/api/v1` · الجلسات `/sessions` · المجموعات `/sessions/groups/{id}`.
> الكتابة: أدمن أو مُطابِق (إعادة الفتح أدمن فقط). القراءة: الجميع. مغلف الخطأ الموحد.

## دورة الحياة

```
إنشاء جلسة → اعتماد كشفنا → اعتماد كشفهم (يرتبطان بالجلسة تلقائياً)
  → اقتراحات المحرك (حالة suggested) → قبول/رفض/ربط يدوي (سحب وإفلات)
  → إغلاق (لقطة ملخص + ورقة تسوية) ⇄ إعادة فتح (أدمن)
```

- **الجلسة أولاً**: `our/their_statement_id` يملآن مرة واحدة عند اعتماد الكشف
  (خانة مشغولة/جلسة مغلقة/حساب مختلف = فشل المعاملة كاملة).
- **التعارض**: جلسة مفتوحة لنفس الحساب والفترة → `409 SESSION_EXISTS` برقمها.

## المسارات

| المسار | الوصف |
|---|---|
| `POST /sessions` | `{accountId, periodLabel(YYYY-MM), openingBalance?}` → 201 `{session}` |
| `GET /sessions?status=` | قائمة + `progress` لكل جلسة (lineCount/total/matchedConfirmed/matchedSuggested/leftover لكل جهة + matchRatePct) |
| `GET /sessions/{id}` | تفصيل شاشة العمل في نداء واحد: الجلسة + المورد + الكشفان ببنودهما (مع `remaining` لكل بند) + `groups` + `progress` + `closeSummary` للمغلقة |
| `POST /sessions/{id}/suggest` | إعادة توليد الاقتراحات (المؤكد والمرفوض لا يُمسّان) → `{suggested:n}` |
| `POST /sessions/{id}/groups` | ربط يدوي (سحب وإفلات): `{items:[{lineId, allocated?}], note?}` → مؤكد فوراً |
| `POST /sessions/{id}/close` | إغلاق بلقطة: `{matchRatePct, totals, discrepancies:[{type ours_only/theirs_only,…}], closedBy}` — تُخزن jsonb وتُعاد في الجواب |
| `POST /sessions/{id}/reopen` | أدمن — يعيد `in_progress→reopened` ويمحو اللقطة |
| `POST /sessions/groups/{id}/confirm` | قبول اقتراح (يعيد التحقق المالي) |
| `POST /sessions/groups/{id}/reject` | رفض اقتراح = إلغاء تفعيل محفوظ — الـpair_key لا يُقترح مجدداً |
| `POST /sessions/groups/{id}/unlink` | فك مؤكد/يدوي — البنود تتحرر |
| `PATCH /sessions/groups/{id}/allocations` | تعديل حصص التوزيع |

## محرّك الاقتراحات (المخزّن لكل حساب: rule_order + date_window_days)

1. `exact_ref` (ثقة 1.0): تطبيع المرجع (أحرف-أرقام فقط) + **تساوي المبلغ بالضبط** (±0.005 — Q11).
2. `ref_map` (0.95): مرجعنا → مرجعهم عبر خريطة المراجع + تساوي المبلغ.
3. `description_ref` (0.8): تقاطع الأرقام المستخرجة من البيانات + تساوي المبلغ.
4. `amount_date` (0.6): تساوي المبلغ + الأقرب زمنياً؛ خارج النافذة يُقترح بثقة 0.3 وملاحظة صريحة ليحكمه المراجع.
5. **التوزيع الجشع** (0.5): دفعة ↔ عدة فواتير، الأكبر أولاً حتى التساوي التام (حد 25 بنداً)؛ ما لم يُوزَّع يبقى متبقياً.

- الاقتراحات حالة `suggested` لا تُلزم — القبول يحوّلها `confirmed` والرفض يحفظ بصمة الزوج (`pair_key`) فلا يتكرر اقتراحها.
- **العمل الآلي (فلسفة الملاحظة الملكية): النظام يبحث ويطابق — لا ينتظر المستخدم:**
  1. لحظة اعتماد الكشف الثاني للجلسة يشتغل المحرك تلقائياً بوضع `auto`.
  2. وضع `auto`: القواعد القطعية (exact_ref/ref_map/description_ref — كلها تتطلب تساوي المبلغ)
     تُحفظ **confirmed** مباشرة: نفس المرجع ونفس المبلغ = نفس المستند، دليل حاسم لا تخمين.
  3. الملتبس فقط (amount_date خارج النافذة/التوزيع الجشع) يبقى `suggested` لمراجعة بشرية.
  4. فتح شاشة جلسة معلقة بكشفين وبلا روابط يشغّل البحث احتياطياً في الواجهة (مرة لكل جلسة).
  5. `POST /suggest` يقبل `mode` ('review' الافتراضي للزر اليدوي / 'auto') ويعيد `{suggested, autoConfirmed}`.
  السحب والإفلات دور الإصلاح فقط: حالات غامضة رفضها المحرك أو أخطاء الملفات.
- **دلالة الحصة**: `allocated` بإشارة البند نفسه (فاتورتنا دائن موجبة وفاتورتهم مدين موجبة)؛
  التوازن = مجموع مطلق حصص كشفنا = نظيره لكشفهم. NULL = كامل البند.
- إعادة التوليد تحذف المقترحات النشطة فقط بعد قياس الاستهلاك (لا خريطة stale).

## التحقق المالي الموحد (Q11) — يدوي/قبول/تعديل

1. البنود تنتمي لكشفي الجلسة، والحصة بإشارة بندها.
2. الحصة ≤ المتاح (|الموقّع| − مستهلك المجموعات الأخرى).
3. التوازن: |Σ|كشفنا| − Σ|كشفهم|| ≤ 0.005 — وإلا 422 برسالة تُظهر الطرفين.

## التدقيق

`SESSION_CREATE/CLOSE/REOPEN`, `MATCH_SUGGEST/CONFIRM/REJECT/UNLINK/MANUAL/ADJUST`.

## الواجهة

- **قائمة الجلسات**: حقيقية بنسب حية + فلاتر + تحديث.
- **المعالج**: الخطوة 1 تنشئ الجلسة (409 يعرض زر الانتقال لها)، الاعتماد يربط الكشفين، الخطوة 4 تفتح شاشة العمل.
- **شاشة العمل**: عمودان للبنود المتبقية (سحب/إفلات أصلي بلا مكتبات)، بناة حصص بتوازن حي،
  بطاقات اقتراح بشارة القاعدة والثقة، شريط صحة، إغلاق بـلقطة + **ورقة تسوية قابلة للطباعة** (نمط A4 الموحد).
- سجل جلسات المورد في تبويبات تفاصيله صار حقيقياً. الوحدات الوهمية حُذفت من الشجرة.
