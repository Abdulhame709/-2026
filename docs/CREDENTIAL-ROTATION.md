# تدوير كلمات المرور القديمة وإبطال الجلسات

هذه الخطوات **تشغيلية** لكل قاعدة بيانات استُخدمت فيها حسابات تجريبية. إزالة كلمة مرور من الشيفرة لا تغيّر التجزئات المخزنة سابقاً. لا يُشغّل الأمر تلقائياً، ولا تدّعِ إكمال التدوير قبل تنفيذه والتحقق من نتائجه في كل بيئة.

1. حدّد قائمة قواعد البيانات المتأثرة والحسابات التي أُنشئت فيها (`admin` و`reconciler` و`viewer` وأي حساب تجريبي آخر). خذ نسخة احتياطية **محمية**، وحدد وقت صيانة وأبلغ المستخدمين بأن جلساتهم ستُلغى. لا تستخدم زر «إجبار تغيير المرور» وحده مع كلمة مرور معروفة: سيظل ممكناً الدخول بالكلمة القديمة حتى يغيّرها صاحب الحساب.
2. على جهاز إداري موثوق، من مجلد `backend`، عيّن اتصال قاعدة البيانات صراحة: `PGHOST` و`PGPORT` إن اختلف عن 5432 و`PGDATABASE` و`PGUSER` و`PGPASSWORD`؛ عيّن `ROTATE_USERNAME` للحساب المستهدف. اتصل محلياً أو عبر نفق/TLS موثوق؛ لا ترسل بيانات الاتصال عبر شبكة مكشوفة ولا تكتب كلمات المرور في ملفات المشروع أو في وسيطات سطر الأوامر.
3. نفّذ `npm run db:rotate -- --check` وتأكد من اسم القاعدة والمضيف والحساب وعدد الجلسات. لا يعرض الفحص كلمات المرور أو التجزئات ولا يعدّل البيانات.
4. أنشئ كلمة مرور **فريدة** لكل حساب بواسطة مدير كلمات مرور، بطول 12 حرفاً على الأقل وتضم حرفاً ورقماً. عيّن `ROTATE_CONFIRM` بصيغة `اسم_القاعدة/اسم_الحساب`، وعيّن `ROTATE_NEW_PASSWORD` مؤقتاً في بيئة العملية، ثم نفّذ `npm run db:rotate -- --apply`. يمسح السكربت متغير كلمة المرور من بيئة عمليته بعد قراءته؛ أزله أيضاً من بيئة الطرفية مباشرة بعد التنفيذ، وأزل `PGPASSWORD` عند إنهاء الصيانة.
5. يعيد الأمر تجزئة الكلمة بــ Argon2id، ويضبط `must_change_password=true`، ويبطل **جميع** جلسات الحساب، ويسجل حدث `CREDENTIAL_ROTATION` في معاملة واحدة. كرّر لكل حساب ولكل قاعدة بيانات؛ سجّل اسم القاعدة والحساب والوقت والنتيجة وعدد الجلسات الملغاة **دون كتابة كلمة المرور**.
6. أعد تشغيل `--check` وتأكد أن الجلسات النشطة صفر وأن تغيير كلمة المرور إلزامي. سلّم الكلمة الجديدة للشخص المخوّل عبر قناة آمنة، واطلب منه تغييرها عند أول دخول؛ اختبر أن الكلمة القديمة مرفوضة وأن الطلبات التجارية مرفوضة حتى يتغير المرور.

مثال PowerShell لتجنّب كتابة الكلمة الجديدة حرفياً في سجل الأوامر، بعد ضبط الاتصال والحساب:

```powershell
cd backend
npm run db:rotate -- --check
$secret = Read-Host 'كلمة مرور جديدة وفريدة' -AsSecureString
try {
  $env:ROTATE_CONFIRM = "$env:PGDATABASE/$env:ROTATE_USERNAME"
  $env:ROTATE_NEW_PASSWORD = [System.Net.NetworkCredential]::new('', $secret).Password
  npm run db:rotate -- --apply
} finally {
  Remove-Item Env:ROTATE_NEW_PASSWORD -ErrorAction SilentlyContinue
  Remove-Item Env:ROTATE_CONFIRM -ErrorAction SilentlyContinue
  $secret.Dispose()
}
```

تنبيه: تبقى كلمات المرور القديمة في نسخ القاعدة السابقة. أمّن النسخ وفق سياسة الاحتفاظ، ولا تستعد نسخة قديمة إلى بيئة متاحة للمستخدمين دون إعادة التدوير وإبطال جلسات الحسابات المتأثرة. هذه الأداة لا تُصلح تسريب حساب قاعدة البيانات نفسه؛ دوّر بيانات اتصال قاعدة البيانات بشكل مستقل عند الحاجة.
